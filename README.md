# LocalVoiceFlow

Локальная диктовка для macOS. Держите **Fn**, говорите, отпускаете — распознанный и
отредактированный текст сам вставляется в то поле, где стоял курсор.

Распознавание речи идёт **полностью на вашем Mac** (MLX Whisper на GPU). В облако уходит
только распознанный текст — для расстановки пунктуации и исправления технических терминов.
**Аудио никогда не покидает компьютер.**

Рассчитано на русскую речь с английскими техническими терминами: «этот юз эффект снова
вызывает фетч» → «Этот useEffect снова вызывает fetch».

## Требования

| Компонент | Версия | Обязателен |
|---|---|---|
| macOS | 14+ (проверено на 26.4) | да |
| Apple Silicon | M1 и новее | да — MLX работает только на Apple GPU |
| Node.js | ≥ 22.5 (проверено на 24.19) | да — нужен встроенный `node:sqlite` |
| pnpm | 9.15+ | да |
| Python | 3.11+ (проверено на 3.14) | да — для MLX Whisper |
| Xcode Command Line Tools | любые актуальные | да — сборка menu-bar агента |
| ffmpeg | любой | только для `make fixtures` |

Плюс **одна из** уже настроенных подписок:

* **Claude** — установленный и залогиненный [Claude Code](https://claude.com/claude-code) (`claude`)
* **OpenAI** — установленный и залогиненный [Codex CLI](https://developers.openai.com/codex/cli/) (`codex`)

API-ключи не нужны и не используются. Приложение работает через **вашу существующую
авторизацию CLI и вашу подписку**.

## Установка

```bash
git clone <repo> && cd wispr_clone
make bootstrap     # проверит инструменты, поставит зависимости, создаст Python venv
make install       # соберёт всё, поставит LaunchAgent, откроет панель управления
```

`make install` не требует `sudo` и ставит всё только в домашнюю папку пользователя.

Проверить, что окружение в порядке:

```bash
make doctor
```

### Выдача разрешений macOS

При первом запуске система запросит три разрешения. Без них диктовка не заработает —
это ограничение macOS, обойти его программно нельзя.

**Системные настройки → Конфиденциальность и безопасность →**

| Раздел | Зачем |
|---|---|
| **Микрофон** | записать голос |
| **Мониторинг ввода** | увидеть нажатие Fn в любом приложении |
| **Универсальный доступ** | вставить готовый текст в чужое поле ввода |

Добавьте туда `LocalVoiceFlow.app`. После выдачи разрешений:

```bash
make restart && make doctor
```

`make doctor` покажет фактический статус каждого разрешения.

### Вход в CLI (если ещё не сделан)

```bash
claude          # /login внутри, вход через claude.ai
codex login     # вход через аккаунт ChatGPT
```

Приложение **не читает** `~/.claude`, `~/.codex` и Keychain — оно просто запускает CLI,
который авторизуется сам.

## Как пользоваться

| Действие | Результат |
|---|---|
| **Зажать Fn**, говорить, **отпустить** | записать и вставить текст |
| **Fn дважды быстро** | режим «руки свободны»: запись продолжается без удержания |
| **Fn ещё раз** (в режиме «руки свободны») | завершить запись |
| **Esc** во время записи или обработки | отменить, **ничего не вставлять** |

Иконка в строке меню показывает состояние: ожидание → запись → распознавание → готово.

### Панель управления

```bash
make start      # выведет ссылку с токеном
```

Открывается в обычном браузере на `http://127.0.0.1:43117`. Там:

* **История** — все диктовки, исходный текст Whisper и финальный текст рядом, плюс
  реально измеренное время каждого этапа. Экспорт в CSV/JSON.
* **Словарь** — ваши термины и варианты произношения. Это главный инструмент качества:
  добавьте сюда имена своих проектов, библиотек и переменных.
* **Настройки** — провайдер, модель, уровень усилий, профили под приложения.
* **Диагностика** — состояние STT, обеих CLI и разрешений.

Панель слушает **только `127.0.0.1`** и требует токен: из сети её не видно.

## Где что лежит

| Что | Путь |
|---|---|
| База истории и словаря | `~/Library/Application Support/LocalVoiceFlow/local-voice-flow.sqlite` |
| Логи | `~/Library/Logs/LocalVoiceFlow/` |
| Токен доступа к панели | `~/Library/Application Support/LocalVoiceFlow/token` (права `0600`) |
| Аудио | по умолчанию **не сохраняется**; включается в настройках |

Всё лежит только локально. Никакой облачной базы, аналитики и телеметрии в проекте нет.

## Команды

```bash
make help        # список всех целей
make start       # запустить
make stop        # остановить
make restart     # перезапустить
make doctor      # диагностика
make test        # TypeScript + Swift + Python тесты
make benchmark   # измерить реальную скорость (тратит квоту подписки)
make fixtures    # перегенерировать аудио-фикстуры (нужен ffmpeg)

make uninstall-purge   # удалить всё, включая историю
```

`make benchmark ARGS="--skip-llm"` меряет только распознавание и **не тратит квоту**.

## Скорость

Замеры на **MacBook Pro M1 Pro**, 42 прогона, `whisper-large-v3-turbo` + Claude Haiku
(`--effort low`). Это фактические числа из `make benchmark`, не обещания:

| Этап | p50 | p95 |
|---|---|---|
| Подготовка аудио | 0 мс | 0 мс |
| Распознавание (локально, GPU) | **717 мс** | 753 мс |
| Подстановка по словарю | 1 мс | 2 мс |
| LLM-редактура (сеть + CLI) | **1938 мс** | 3477 мс |
| **Итого** | **2149 мс** | 3647 мс |

Распознавание — доли секунды. Основное время уходит на облачную редактуру: запуск CLI и
сетевой round-trip. Быстрее всего связка Haiku + `effort: low`; она же стоит по умолчанию.

Для сравнения, тот же прогон через Codex (`gpt-5.6-luna`, `effort: none`): LLM p50
**6346 мс**, итого p50 **6378 мс** — примерно втрое медленнее. Поэтому провайдером по
умолчанию выбран Claude, а Codex остаётся резервным вариантом.

Время каждой диктовки записывается в историю, так что реальную скорость на своей машине
видно всегда.

## Приватность

* Аудио обрабатывается локально и **никуда не отправляется**.
* В LLM уходит только распознанный текст, подобранные термины словаря и название активного
  приложения. Заголовок окна **не** отправляется, пока вы сами не включите это.
* Токены не хранятся в проекте; `~/.claude`, `~/.codex` и Keychain не читаются.
* Ключи `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` принудительно удаляются из окружения
  дочернего процесса, чтобы случайно не уйти с подписки на платный API-ключ.
* Текст передаётся в CLI через **stdin**, а не через аргументы командной строки, и никогда
  через shell — продиктованная фраза не может стать командой.
* Ни аналитики, ни телеметрии, ни внешних трекеров.

## Если что-то не работает

Сначала — `make doctor`: он проверяет разрешения, ядро, модель и обе CLI и пишет, что
именно чинить.

| Симптом | Причина |
|---|---|
| Fn не реагирует | нет «Мониторинга ввода» → выдать и `make restart` |
| Текст не вставляется | нет «Универсального доступа» |
| Пустая диктовка | нет доступа к микрофону, либо говорили слишком тихо |
| `llm_cli_missing` | `claude` / `codex` не в `PATH` |
| `llm_unauthenticated` | войти: `claude` → `/login`, либо `codex login` |
| Долгая первая диктовка | модель Whisper скачивается один раз (~1.5 ГБ) |
