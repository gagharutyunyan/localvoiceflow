# LocalVoiceFlow

Локальная диктовка для macOS. Держите **Fn**, говорите, отпускаете — распознанный и
отредактированный текст сам вставляется в то поле, где стоял курсор.

Распознавание речи идёт **полностью на вашем Mac** (MLX Whisper на GPU). В облако уходит
только распознанный текст — для расстановки пунктуации и исправления технических терминов.
**Аудио никогда не покидает компьютер.**

Рассчитано на русскую речь с английскими техническими терминами: «этот юз эффект снова
вызывает фетч» → «Этот useEffect снова вызывает fetch».

Язык диктовки выбирается в настройках: русский, английский, армянский (`hy`) или
автоопределение по самой записи.

## Требования

| Компонент | Версия | Обязателен |
|---|---|---|
| macOS | 14+ (проверено на 26.4) | да |
| Apple Silicon | M1 и новее | да — MLX работает только на Apple GPU |
| Node.js | ≥ 22.5 (проверено на 24.19) | да — нужен встроенный `node:sqlite` |
| pnpm | 9.15+ | да |
| Python | 3.11+ (проверено на 3.14) | да — для MLX Whisper |
| Xcode Command Line Tools | любые актуальные | да — сборка menu-bar агента |
| ffmpeg | любой | только для `make fixtures` |

Плюс **одна из** уже настроенных подписок:

* **Claude** — установленный и залогиненный [Claude Code](https://claude.com/claude-code) (`claude`)
* **OpenAI** — установленный и залогиненный [Codex CLI](https://developers.openai.com/codex/cli/) (`codex`)

API-ключи не нужны и не используются. Приложение работает через **вашу существующую
авторизацию CLI и вашу подписку**.

## Установка

Сначала получите код:

```bash
git clone https://github.com/gagharutyunyan/localvoiceflow.git
cd localvoiceflow
```

Дальше три команды, по порядку:

```bash
make bootstrap     # 1. проверит инструменты, поставит зависимости, создаст Python venv
make install       # 2. соберёт всё и запустит
```

Приложение откроет окно с тремя разрешениями macOS — по кнопке на каждое. После них можно
говорить. Проверить в любой момент:

```bash
make status        # запущено ли всё и можно ли уже говорить
```

`make install` не требует `sudo` и ставит всё только в домашнюю папку. Повторный запуск —
это переустановка поверх: история, словарь и настройки сохраняются. Если код не менялся,
приложение не пересобирается, поэтому **выданные разрешения не сбрасываются**.

### Разрешения macOS

Нужны три. Без них диктовка не работает физически — это защита самой macOS, выдать их
программно невозможно.

| Разрешение | Зачем | Что сломано без него |
|---|---|---|
| **Микрофон** | записать голос | ничего не записывается |
| **Мониторинг ввода** | поймать Fn в любом приложении | **клавиша Fn не реагирует** |
| **Универсальный доступ** | вставить текст под курсор | текст распознан, но не вставлен |

Приложение показывает окно с этими тремя пунктами само, когда чего-то не хватает. У каждого —
кнопка: macOS покажет своё окно, в нём «Открыть Системные настройки», дальше остаётся включить
переключатель. Галочки в окне обновляются сами, никаких перезапусков вручную.

Окно можно открыть в любой момент: значок микрофона в строке меню → **«Настроить разрешения…»**.
Команда `make permissions` делает то же самое — запускает приложение, если оно не запущено.

**Разрешения выдаются один раз.** Это стоит отдельного упоминания, потому что раньше было не
так. macOS привязывает их к подписи приложения, а без сертификата `codesign` подписывает
ad-hoc — то есть «подписью» служит хэш бинарника, и любая пересборка выглядела для системы
как другая программа, у которой разрешений нет. `scripts/signing-identity.sh` создаёт
постоянный локальный сертификат (один раз, автоматически при сборке), и требование к подписи
становится таким:

```
designated => identifier "com.localvoiceflow.agent" and certificate leaf = H"73d81f…"
```

Обе половины переживают пересборку — значит, и разрешения тоже.

### Запуск при входе в систему

Приложение добавляет себя в «Объекты входа» при первом запуске — иначе после перезагрузки
значок не появился бы, и диктовка молча не работала бы до тех пор, пока приложение не откроют
руками. Перетаскивать его в список вручную не нужно.

Выключить можно в двух местах: значок микрофона в строке меню → **«Запускать при входе в
систему»**, либо Системные настройки → Основные → Объекты входа. Выключение запоминается —
приложение не включит автозапуск обратно.

Ядро (распознавание и история) поднимается отдельно, через LaunchAgent, который ставит
`make install`.

### Можно диктовать, не дожидаясь разрешений

Резервное сочетание **⌃⌥Space** сделано на Carbon `RegisterEventHotKey` — ему «Мониторинг ввода»
**не нужен вообще**. А без «Универсального доступа» готовый текст не пропадает: он кладётся в
буфер обмена, останется нажать **⌘V**.

То есть даже с двумя невыданными разрешениями цепочка работает целиком:

**⌃⌥Space** → говорите → **⌃⌥Space** → **⌘V**

Одно ограничение: отмена по **Esc** работает только при выданном «Мониторинге ввода» —
Esc ловится тем же event tap'ом, что и клавиша Fn (самому резервному сочетанию, Carbon-хоткею,
этот tap не нужен). Пока разрешения нет, запись, начатую через ⌃⌥Space, нельзя отменить
Esc'ом — только завершить повторным ⌃⌥Space.

Разрешения нужны только для удобства: «Мониторинг ввода» — чтобы работали клавиша **Fn**
и отмена по **Esc**, «Универсальный доступ» — чтобы текст вставлялся сам, без ⌘V.

### Вход в CLI (если ещё не сделан)

```bash
claude          # /login внутри, вход через claude.ai
codex login     # вход через аккаунт ChatGPT
```

Приложение **не читает** `~/.claude`, `~/.codex` и Keychain — оно просто запускает CLI,
который авторизуется сам.

## Как пользоваться

| Действие | Результат |
|---|---|
| **Зажать Fn**, говорить, **отпустить** | записать и вставить текст |
| **Fn дважды быстро** | режим «руки свободны»: запись продолжается без удержания |
| **Fn ещё раз** (в режиме «руки свободны») | завершить запись |
| **Esc** во время записи или обработки | отменить, **ничего не вставлять** |

Иконка в строке меню показывает состояние: ожидание → запись → распознавание → готово.

### Панель управления

```bash
make start      # выведет ссылку с токеном
```

Открывается в обычном браузере на `http://127.0.0.1:43117`. Там:

* **История** — все диктовки, исходный текст Whisper и финальный текст рядом, плюс
  реально измеренное время каждого этапа. Экспорт в CSV/JSON.
* **Словарь** — ваши термины и варианты произношения. Это главный инструмент качества:
  добавьте сюда имена своих проектов, библиотек и переменных. Из коробки там ~350 терминов
  разговорного программирования на русском: Claude Code и Claude Design, MCP, хуки React,
  Git, shell, Swift/Xcode, соглашения об именовании. У каждого термина есть **приоритет**
  (`priority`, 0–100): подсказка Whisper вмещает лишь около двадцати слов, и приоритет
  решает, кто их займёт — остальные термины исправляются уже после распознавания.
* **Настройки** — провайдер, модель, уровень усилий, профили под приложения.
* **Диагностика** — состояние STT, обеих CLI и разрешений.

Панель слушает **только `127.0.0.1`** и требует токен: из сети её не видно.

## Где что лежит

| Что | Путь |
|---|---|
| База истории и словаря | `~/Library/Application Support/LocalVoiceFlow/local-voice-flow.sqlite` |
| Логи | `~/Library/Logs/LocalVoiceFlow/` |
| Токен доступа к панели | `~/Library/Application Support/LocalVoiceFlow/token` (права `0600`) |
| Аудио | по умолчанию **не сохраняется**; включается в настройках |

Всё лежит только локально. Никакой облачной базы, аналитики и телеметрии в проекте нет.

## Команды

```bash
make help        # список всех целей
make status      # запущено ли всё и можно ли говорить
make permissions # пошагово выдать разрешения macOS
make dashboard   # открыть панель управления

make stop        # остановить
make restart     # перезапустить
make doctor      # подробная диагностика
make test        # TypeScript + Swift + Python тесты
make benchmark   # измерить реальную скорость (тратит квоту подписки)
make fixtures    # перегенерировать аудио-фикстуры (нужен ffmpeg)
make uninstall   # удалить приложение, данные оставить
make uninstall-purge   # удалить всё, включая историю
```

`make benchmark ARGS="--skip-llm"` меряет только распознавание и **не тратит квоту**.

## Скорость

Замеры на **MacBook Pro M1 Pro**, 42 прогона, `whisper-large-v3-turbo` + Claude Haiku
(`--effort low`). Это фактические числа из `make benchmark`, не обещания:

| Этап | p50 | p95 |
|---|---|---|
| Подготовка аудио | 0 мс | 0 мс |
| Распознавание (локально, GPU) | **717 мс** | 753 мс |
| Подстановка по словарю | 1 мс | 2 мс |
| LLM-редактура (сеть + CLI) | **1938 мс** | 3477 мс |
| **Итого** | **2149 мс** | 3647 мс |

Распознавание — доли секунды. Основное время уходит на облачную редактуру: запуск CLI и
сетевой round-trip. Быстрее всего связка Haiku + `effort: low`; она же стоит по умолчанию.

Для сравнения, тот же прогон через Codex (`gpt-5.6-luna`, `effort: none`): LLM p50
**6346 мс**, итого p50 **6378 мс** — примерно втрое медленнее. Поэтому провайдером по
умолчанию выбран Claude, а Codex остаётся резервным вариантом.

Время каждой диктовки записывается в историю, так что реальную скорость на своей машине
видно всегда.

## Приватность

* Аудио обрабатывается локально и **никуда не отправляется**.
* В LLM уходит только распознанный текст, подобранные термины словаря и название активного
  приложения. Заголовок окна **не** отправляется, пока вы сами не включите это.
* Токены не хранятся в проекте; `~/.claude`, `~/.codex` и Keychain не читаются.
* Ссылка на панель содержит токен доступа и печатается в терминал при каждом запуске —
  она остаётся в scrollback терминала и в истории браузера. Для локального
  однопользовательского инструмента это осознанный компромисс (так же работает Jupyter):
  панель слушает только `127.0.0.1`, токен лежит в файле с правами `0600` и полезен лишь
  тому, кто уже вошёл на этот Mac под вашим пользователем. Сменить токен: удалите
  `~/Library/Application Support/LocalVoiceFlow/token` и выполните `make restart` —
  ядро сгенерирует новый.
* Ключи `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` принудительно удаляются из окружения
  дочернего процесса, чтобы случайно не уйти с подписки на платный API-ключ.
* Текст передаётся в CLI через **stdin**, а не через аргументы командной строки, и никогда
  через shell — продиктованная фраза не может стать командой.
* Ни аналитики, ни телеметрии, ни внешних трекеров.

## Если что-то не работает

Сначала — `make doctor`: он проверяет разрешения, ядро, модель и обе CLI и пишет, что
именно чинить.

| Симптом | Причина |
|---|---|
| Fn не реагирует | нет «Мониторинга ввода» → выдать и `make restart` |
| Текст не вставляется | нет «Универсального доступа» |
| Пустая диктовка | нет доступа к микрофону, либо говорили слишком тихо |
| `llm_cli_missing` | `claude` / `codex` не в `PATH` |
| `llm_unauthenticated` | войти: `claude` → `/login`, либо `codex login` |
| Долгая первая диктовка | модель Whisper скачивается один раз (~1.5 ГБ) |
